One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer, judged in private pairs by an AI judge. Free to enter, one line per entry.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/loading-screen-gold-26nov-out python3 main.py
```

This writes a single line — one loading-screen tip of at most 200 characters —
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable
is unset). Run it twice and the output is byte-identical.
